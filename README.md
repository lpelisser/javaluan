Exercícios Java

Coleção de exercícios práticos em Java, focados em fundamentos da linguagem: entrada de dados, laços, arrays, condicionais e componentes gráficos simples.

📂 Arquivos
Arquivo	Descrição
App.java	Calcula a idade total em dias a partir de anos, meses e dias informados pelo usuário.
ex2.java	Calcula a média de dois arrays de números e a média entre as duas médias.
ex3.java	Calcula quantos salários mínimos cabem em um valor informado pelo usuário.
ex4.java	Verifica se um número inteiro digitado é par ou ímpar.
luan.java	Formulário simples com JOptionPane para captura de nome, idade e objetivo de vida.
Revisao.java	Exercício de revisão — mesma lógica de cálculo de idade em dias do App.java.
MediaExtra.java	Calcula a média de um array fixo de números.
▶️ Como executar

Cada arquivo é independente e contém seu próprio método main. Para rodar qualquer um deles:

bash
javac NomeDoArquivo.java
java NomeDoArquivo

Exemplo:

bash
javac App.java
java App
🛠️ Tecnologias
Java (JDK 8+)
Scanner para entrada via terminal
JOptionPane (Swing) para entrada via caixas de diálogo
📌 Observações
Os exercícios foram organizados um por classe/arquivo, conforme exigido pelo Java para classes públicas.
Pequenos ajustes de sintaxe foram feitos para garantir que todos compilem corretamente (operadores de multiplicação, imports e formatação de saída).
